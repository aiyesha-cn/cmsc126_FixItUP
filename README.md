## CMSC 126 Final Project

FixItUP: A WEB-BASED FACILITY MAINTENANCE AND SERVICE PLATFORM

The key objective of this project is to provide the community within the campus with a convenient and organized way for them to report damaged facilities and maintenance issues within the campus. By creating this system, students, faculty, and staff will no longer need to rely on informal methods such as verbal reports or manual requests when reporting facility maintenance problems. Through this project, they can quickly submit maintenance requests and receive updates regarding the status of the repair. This system helps ensure that facility issues are properly documented and addressed, contributing to a safer and more functional campus environment.

Software used:
- PHP (Laravel)
- React.js
- HTML
- Tailwind CSS
- XAMPP
    - MySQL
